RENZIE GACOT — PORTFOLIO WEBSITE
================================

Files:
  index.html   the page
  style.css    the design
  script.js    menu, project filters, fade-in, poster lightbox
  img/         put your images here
  cv/          your CV (Renzie_Gacot_CV.pdf) - to update it, replace this file with the same name

1) IMAGES: all images are already in the img folder. The site no longer depends on Lovable.

2) PUT IT ONLINE FREE WITH GITHUB PAGES:
   - On github.com/renzieee create a new repo named:  renzieee.github.io
   - Upload index.html, style.css, script.js, the img folder and the cv folder.
   - Settings > Pages > Source: "Deploy from a branch", branch: main, folder: / (root).
   - After about a minute your site is live at  https://renzieee.github.io

3) YOUR CV is already included in the cv folder. Upload the cv folder to GitHub too.

4) PROJECTS FOLDER: projects/digit-recognizer/ is the AI demo.
   Upload the whole "projects" folder to GitHub too. It will be live at
   https://renzieee.github.io/projects/digit-recognizer/
   train.py is the Python code that trains the model (python train.py).
